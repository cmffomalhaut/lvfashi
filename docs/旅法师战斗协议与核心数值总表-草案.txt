<战斗协议>
战斗:
  核心指令: 仅当存在明确敌对双方且将会进入战斗时激活，其余非战斗情境禁止触发

# 第一阶段: 战况总览
  逻辑与规则:
    1. 每回合开始输出一次战况总览
    2. 必须列出全部参战单位的HP、MP、核心属性、当前状态、敌人类型与是否为集群
    3. 敌人类型固定分为[杂兵]/[精英]/[Boss]
    4. 杂兵优先适用集群规则；精英与Boss默认作为独立单位处理，除非剧情明确说明

  面板模板:
  <action_info>
    {战况总览}
    | 回合: [当前回合数] | 战斗类型: [切磋/竞技/压制/标准/守卫/死斗] | 环境: [简述环境/距离] |
    | [单位A]: HP [X/X] | MP [X/X] | 力[X] 敏[X] 体[X] 感[X] 智[X] | 类型: [杂兵/精英/Boss] | 集群: [是/否] |
    | 状态: [状态A, 状态B, 状态C] |
    | [单位B]: HP [X/X] | MP [X/X] | 力[X] 敏[X] 体[X] 感[X] 智[X] | 类型: [杂兵/精英/Boss] | 集群: [是/否] |
    | 状态: [状态A, 状态B, 状态C] |
    | ...列出全部参战单位 |
  </action_info>
  叙事指导: 描写当前对峙局势、环境压力、层级差带来的威压感与角色状态

# 第二阶段: 行动顺序
  逻辑与规则:
    1. 每回合开始重新计算一次全体行动值
    2. 行动值公式: '敏捷 + d20 + 固定修正'
    3. 我方、队友、敌方全部进入同一行动轴，按总值从高到低行动
    4. 百分比速度修正不作为常规规则；如需特殊改序，优先写成固定修正或直接提前/延后若干位

  面板模板:
  <action_info>
    {行动顺序}
    | [角色A]: 敏捷[X] + 骰[Y] + 固定修正[Z] = [总值] |
    | [角色B]: 敏捷[X] + 骰[Y] + 固定修正[Z] = [总值] |
    | 序列: [角色A] -> [角色B] -> [角色C] -> ... |
  </action_info>
  叙事指导: 描写谁率先出手、谁被压制、谁因状态或层级差而动作迟滞

# 第三阶段: 攻击行动
  逻辑与规则:
    1. 每单位每回合拥有1[攻击]
    2. 普攻、攻击技能、伤害法术、带攻击性质的特殊术式均消耗1[攻击]
    3. 命中总值: 'max(技能命中, 装备命中) + 状态命中修正'
    4. 闪避总值: 'max(技能闪避, 装备闪避) + 状态闪避修正'
    5. 评级总值: 'd20 + 命中总值 - 闪避总值'
    6. 四档评级:
      - '≤6 = 失手(0倍)'
      - '7-12 = 擦伤(0.5倍)'
      - '13-18 = 有效(1.0倍)'
      - '≥19 = 暴击(1.5倍)'
    7. 基础伤害公式: '关联属性 × 10 × 层级系数 + 技能威力 + 装备攻击'
    8. 最终伤害公式: '基础伤害 × 评级系数 × 层级压制修正 × 其他修正'
    9. 低层对高层若无特殊手段，必须先服从层级压制总则，不得按同层正常结算
    10. 特殊手段仅包括: 明确属性克制、预先布置的仪式、场地或地脉共鸣、已识破并命中的术式弱点、高代价破阶技能、剧情已确认的位格裂口或本质缺陷
    11. 若仅差1级但跨了层级，允许通过充分准备与高代价资源艰难取胜，但不得忽视层级压制

  层级压制总则:
    层级:
      第一层: 1-15级, 对应0=0至4=7
      第二层: 16-27级, 对应5=6至8=3
      第三层: 28-31级, 对应9=2至10=1
    命中压制:
      同层: 1d20
      高一层打低一层: 2d20取高, 低层闪避修正减半
      低一层打高一层: 2d20取低, 高层闪避修正视为双倍
      高两层打低两层: 2d20取高, 低层闪避修正无效, 命中评级保底为有效
      低两层打高两层: 无特殊手段时攻击检定直接无效; 有特殊手段时2d20取低
    伤害压制:
      同层: 正常结算
      高一层打低一层: 最终伤害×1.5
      低一层打高一层: 最终伤害×0.5; 无特殊手段时单次伤害上限不得超过目标最大HP的10%
      高两层打低两层: 最终伤害×2.0
      低两层打高两层: 无特殊手段时最终伤害视为0; 有特殊手段时最终伤害×0.25, 单次伤害上限不得超过目标最大HP的15%
    状态与控制压制:
      高一层打低一层: 控制类、削弱类、沉默类、禁锢类检定+5
      低一层打高一层: 控制类、削弱类、沉默类、禁锢类检定-5; 无特殊手段时处决、抹杀、概念破坏默认不能成立
      高两层打低两层: 控制类、削弱类、沉默类、禁锢类效果默认优先成立; 低层常规抗性减半
      低两层打高两层: 无特殊手段时控制类、削弱类、处决类效果直接无效; 有特殊手段时相关检定-10, 即使成功也默认仅造成短时削弱、破绽或局部失衡; 只有“特殊手段成立+暴击评级”时才允许判定为极低概率重创

  集群规则:
    1. 集群用于同类低级单位数量较多的情况
    2. 杂兵优先进入集群；精英与Boss默认不进入集群
    3. 高一层攻击第一层杂兵集群时，应允许出现“一次高稀有度大招直接清场”的结果

  面板模板:
  <action_info>
    {攻击行动}
    | 攻方: [攻击者] | 守方: [目标] | 技能/术式: [名称] | 装备: [名称] |
    | 消耗: 攻击[1] | MP [X] |
    | 命中总值: max(技能命中[A], 装备命中[B]) + 状态命中修正[C] = [D] |
    | 闪避总值: max(技能闪避[E], 装备闪避[F]) + 状态闪避修正[G] = [H] |
    | 检定: d20[I] + 命中[D] - 闪避[H] = [J] -> [失手/擦伤/有效/暴击] |
    | 基础伤害: [关联属性]×10×[层级系数] + [技能威力] + [装备攻击] = [K] |
    | 压制修正: [层级压制说明] = [L] |
    | 最终伤害: [K] × [评级系数] × [L] × [其他修正] = [M] |
    | 变更: [目标] HP [旧值] -> [新值] |
    | 状态: [施加/未施加] [状态说明] |
  </action_info>
  叙事指导: 描写打击质量、术式压制、越级失败或破阶成功的具体表现

# 第四阶段: 战术动作
  逻辑与规则:
    1. 每单位每回合拥有1[动作]
    2. 防御、道具、逃跑、蓄力、位移、格挡、专注、辅助性术式均消耗1[动作]
    3. 伤害型道具转入攻击行动结算
    4. 逃跑必须服从层级压制中的逃跑修正
    5. 逃跑压制:
      - 同层: 正常检定
      - 低一层面对高一层: 逃跑检定-5
      - 低两层面对高两层: 逃跑检定-10
      - 高层追击低层: 高一层视为+5, 高两层视为+10

  面板模板:
  <action_info>
    {战术动作}
    | 角色: [行动者] | 类型: [防御/道具/逃跑/蓄力/位移/格挡/专注/辅助术式] | 对象: [目标] |
    | 消耗: 动作[1] | MP [X] |
    | 执行: [动作说明] |
    | 效果: [恢复/增益/减益/位移/防御姿态/准备状态] |
  </action_info>
  叙事指导: 描写动作的具体表现、准备感与战场节奏变化

# 第五阶段: 战意判定
  逻辑与规则:
    1. 仅非玩家单位触发战意判定
    2. 当目标当前HP低于其战斗类型对应阈值时触发
    3. 切磋/竞技/压制触发后默认进入战意动摇
    4. 标准/守卫/死斗触发后进行战意检定
    5. 战意检定: 'd20 < 12 = 丧失战意/崩溃; d20 ≥ 12 = 勉强坚持'
    6. 层级压制会提前战意触发阈值:
      - 面对高一层: +10%
      - 面对高两层: +20%
    7. 高层在本回合造成暴击、强压制或处决宣言时，可额外触发一次战意动摇检定
    8. Boss可延后触发阈值，并对普通战意动摇具备额外抗性

  战斗类型阈值:
    切磋: 40%
    竞技: 30%
    压制: 50%
    标准: 30%
    守卫: 35%
    死斗: 10%

  结果池:
    - 投降
    - 认输
    - 求饶
    - 溃逃
    - 撤退
    - 被击昏
    - 被俘虏
    - 中止战斗
    - 阵线溃散
    - 内讧

  面板模板:
  <action_info>
    {战意判定}
    | 目标: [角色名] | 当前HP: [当前/最大] | 战斗类型: [类型] |
    | 阈值: [基础阈值] + [层级修正] = [实际阈值] |
    | 判定: d20[X] -> [战意动摇/崩溃/勉强坚持] |
    | 结果: [投降/求饶/溃逃/撤退/被俘等] |
  </action_info>
  叙事指导: 描写心理防线崩塌、威压震慑、阵型松动与求生反应

# 第六阶段: 战斗结算
  逻辑与规则:
    1. 只有一方全灭、溃逃、投降或成功脱战时输出
    2. 写入胜败结果、核心战果、状态结算、掉落结算与世界.近期事务覆盖
    3. 杂兵应更容易被高层快速清场；精英与Boss必须通过额外倍率拉开生存时间
    4. 低层面对高层时，常规手段应明显吃力，但允许通过仪式、装备、状态、道具、高稀有度技能等组合资源费力打过

  面板模板:
  <action_info>
    {战斗结算}
    | 结果: [胜利/失败/脱战成功/中止战斗] |
    | 战果: [简述战局结果] |
    | 状态结算: [保留/转化/移除的状态] |
    | 掉落结算: [掉落物/无] |
    | 近期事务: [一句话覆盖写入世界.近期事务] |
  </action_info>
  叙事指导: 描写战后余波、胜败差异与残局处理
</战斗协议>

# 控制门槛
普通: 不能施加硬控，仅能造成轻微干扰
优秀: 可造成轻度限制，通常不应完整剥夺回合
稀有: 可施加沉默、迟缓、短禁锢
史诗: 可稳定施加沉默、禁锢、眩晕
传说: 可施加强控，但仍受层级压制与抗性制约
神话: 可施加高强度控制或复合控制，但不得无视层级压制总则

# 状态持续时间(按稀有度)
普通: 1回合

稀有: 2回合
史诗: 3回合
传说: 4回合
神话: 5回合

# 状态生成格式
状态名
效果类型: 增益 | 减益 | 持续伤害 | 控制 | 特殊
数值: 必须数值化
层数: 默认1; 若支持叠加, 必须说明每层效果与叠加上限
持续时间: 按稀有度默认时长, 或由技能特殊说明覆盖
来源: 技能/卡牌/装备/道具/仪式/环境/召唤物/其他
解除方式: 净化/休息/特定道具/受击解除/条件解除/持续结束/其他
结算时机: 回合开始 | 受击时 | 回合结束 | 触发时

# 状态补充约束
状态名由AI或技能设计自由生成, 但应简洁可辨识
若状态具有触发条件, 必须写明, 如: 受到攻击时 | HP低于30%时 | 尝试施法时 | 回合结束时
若状态可叠层, 必须补充:
  - 每层效果
  - 最大层数
  - 同源叠加规则
  - 异源叠加规则
默认叠层口径:
  同名同源: 优先刷新时间, 其次增层
  同名异源: 默认独立计时; 若过于复杂, 可改为取最高值

# 默认状态结算时机
回合开始时结算: 属性增益 | 属性减益 | 行动值修正
受击时结算: 护幕 | 易伤 | 反伤
回合结束时结算: 中毒 | 灼烧 | 撕裂 | 咒蚀
触发时结算: 战意侵蚀 | 反制印记 | 断法
