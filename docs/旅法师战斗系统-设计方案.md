# 战斗系统设计

> 旅法师卡牌系统 — 战斗子系统
> 2026-05-25

---

## 一、回合结构

### 1.1 先手检定（开战前）

```
d20 + 感知修正 vs DC

  我方主动偷袭   → DC12 → 成功: 我方全员先动一轮免费轮 → 进入交替
  正常遭遇      → DC15 → 成功: 我方先手 → 进入交替
                         失败: 敌方先手 → 进入交替
  被偷袭        → DC18 → 成功: 正常交替
                         失败: 敌方全员先动一轮免费轮 → 进入交替
```

先手检定由AI用骰子池第1个d20执行。偷袭/被偷袭由剧情决定。

### 1.2 交替回合

```
我方回合：我方全员行动 → AI叙事我方行动+敌方反应
敌方回合：敌方全员行动 → AI叙事敌方行动+我方反应
重复
```

### 1.3 每角色每回合

```
2个主动技能 + 1个动作

动作选项:
  防御  — 本回合受伤害减半
  道具  — 使用一个子类别=战斗的已加载道具卡牌
  逃跑  — 花费动作做逃跑检定（见1.6）
  蓄力  — 蓄力，下回合释放（某些技能需要蓄力）
```

## 二、命中与暴击

### 2.1 命中公式

```
攻击方: d20 + 敏修正
防守方: 10 + 敏修正 + 闪避加成（装备/被动）

攻击方总和 ≥ 防守方总和 → 命中
```

### 2.2 暴击

```
d20出目 ≥ 16 → 暴击
暴击伤害 = 公式伤害 × 1.5
```

对群体攻击：暴击判定每个目标独立（但共用同一个d20的结果来做判定）。
例：群攻用d20#3=17，对所有目标都做暴击判定(d20=17≥16→暴击)，都×1.5。

### 2.3 伤害公式

```
物理伤害 = 攻击方力量 × 技能倍率 − 防守方体质    （最低1）
魔法伤害 = 攻击方智力 × 技能倍率 − 防守方感知    （最低1）
治疗    = 施法方智力 × 技能倍率
```

### 2.4 伤害波动

```
最终伤害 = 公式伤害 × 波动系数
波动系数: 0.8 ~ 1.2（用骰子池下一个d20映射: 1→0.8, 20→1.2，线性）
```

## 三、群攻

```
群体攻击对每个目标独立计算命中（共用一个d20），然后独立计算伤害。

群攻额外检定: 用一个d20做质量检定
  d20 ≥ 16: 全额伤害 + 允许暴击
  d20 10~15: 正常伤害，不能暴击
  d20 ≤ 9: 伤害减半

此检定只需要一个d20，结果适用于所有目标。
```

## 四、状态效果

### 4.1 状态列表

| 状态 | 效果 | 持续时间 |
|------|------|:--:|
| 攻↑ | 力量/智力 +3 | 品质决定 |
| 防↑ | 受伤害时体质/感知 +3 | 品质决定 |
| 敏↑ | 敏捷 +3（影响命中/闪避/逃跑） | 品质决定 |
| 中毒 | 每回合结束时掉血 = 3×品质等级 | 品质决定 |
| 灼烧 | 每回合结束时掉血 = 2×品质等级，可叠加（最多3层） | 品质决定 |
| 麻痹 | 50%概率跳过行动（用d20: 1-10跳过, 11-20正常） | 品质决定 |
| 睡眠 | 跳过行动，直到被打醒（受伤害自动醒来） | 最多品质+1回合 |
| 混乱 | 随机攻击目标（50%友方, 50%敌方） | 品质决定 |
| 沉默 | 不能使用主动技能，只能普攻/防御/道具/逃跑 | 品质决定 |
| 冰冻 | 敏捷减半 + 30%概率跳过行动（d20: 1-6跳过） | 品质决定 |

### 4.2 持续时间（品质）

```
普通: 1回合
稀有: 2回合
史诗: 3回合
传说: 4回合
```

施加状态时AI注明"持续N回合"，每回合结束时倒计时。

## 五、技能

### 5.1 技能来源

```
旅法师技能:
  ├─ 羁绊卡牌（每张提供1个技能）
  ├─ 技能卡牌（主动技能）
  └─ 资源: MP + 使用次数(长休重置)，MP消耗和次数由品质决定

队友技能:
  ├─ 2主动 + 1被动，加入时AI根据角色背景一次性生成
  ├─ 资源: 纯MP消耗
  └─ 技能数值AI自由设定（基于角色背景，在战斗prompt中写明）

敌人技能:
  └─ 遭遇时设定，AI自行决定数值
```

### 5.2 品质 → 技能数值（AI自由发挥，仅给参考范围）

```
品质参考范围:
  普通: 倍率1.2-1.5  MP消耗3-5  次数5-7
  稀有: 倍率1.5-2.0  MP消耗6-10 次数4-5
  史诗: 倍率2.0-2.8  MP消耗11-18 次数2-3
  传说: 倍率2.5-3.5  MP消耗16-25 次数1-2

AI自行在范围内设定具体数值。
```

### 5.3 技能类型

```
物理攻击 — 力量 × 倍率 − 对方体质
魔法攻击 — 智力 × 倍率 − 对方感知
治疗    — 智力 × 倍率
增益    — 给友方上BUFF（攻↑/防↑/敏↑）
减益    — 给敌方上DEBUFF（攻↓/防↓/敏↓/毒/麻痹/睡眠/混乱/沉默/灼烧/冰冻）
```

### 5.4 被动技能

```
队友和特殊敌人(Boss)可拥有被动技能。

被动效果约束: 强度约为主动技能的1/3
示例: 「每回合回复3HP」「受到火属性伤害减半」「HP低于一半时力量+2」

具体效果AI根据角色背景自由设计。
```

## 六、逃跑

```
花费1个动作 → 逃跑检定:
  d20 + 我方敏修正 vs 敌方最高敏捷 + 10

成功: 全体脱离战斗。HP/MP/状态保持当前。
失败: 浪费该动作，本回合其余角色继续行动。
```

---

## 七、道具

```
新卡牌类别: 道具
  子类别: "战斗" | "日常" | ""

战斗prompt只取 类别=道具 且 子类别=战斗 的已加载道具卡牌。

道具效果/数值AI自由设计。
战斗道具示例: 回复药(回HP)、魔力药(回MP)、解毒草(解毒)、炸弹(群攻伤害)

非战斗道具(子类别≠战斗)不会出现在战斗prompt中。
```

---

## 八、HP归零

```
脚本只保证 HP 不低于 0。

HP归零后的具体后果由 AI 按剧情裁定：
  ├─ 倒地
  ├─ 昏迷
  ├─ 战败
  ├─ 被俘
  ├─ 撤退
  └─ 重伤或其他剧情代价

HP归零不自动死亡、不自动删档，也不自动施加固定长期惩罚。
全员 HP 为 0 时，战斗通常视为失败，但失败后的剧情后果仍由 AI 裁定。
```

---

## 九、MP与技能消耗

```
旅法师:
  ├─ 主动技能: MP消耗（看品质） + 使用次数-1（长休重置）
  ├─ 普通攻击: 不消耗MP和次数
  └─ 技能卡牌次数=0时该技能不可用

队友:
  ├─ 主动技能: 纯MP消耗
  ├─ 普通攻击: 不消耗
  └─ 无次数限制

MP消耗: 品质越高消耗越大，AI在设计卡牌/技能时自由设定。
MP不足时该技能不可用。
```

## 十、地牌被动效果

```
地牌效果由AI在每回合开始时体现并计算：
  ├─ 每回合MP回复: +N MP/人
  ├─ 每回合HP回复: +N HP/人
  ├─ 速度修正: 敏捷附加值（仅影响命中/闪避/逃跑，不改变行动顺序）
  └─ 其他特殊效果AI根据卡牌描述自行发挥

AI在回合开始时结算地牌效果（回血/回蓝等）。
```

## 十一、敌人

```
敌人由战斗API的AI全权控制：
  ├─ 自行决定用什么技能
  ├─ 自行选择攻击目标
  ├─ 自行判断何时治疗/防御
  └─ HP低时AI合理表现出自保行为

普通敌人没有被动技能。
特殊敌人(Boss)可拥有1-2个被动技能（效果由AI设定，遵循被动强度约束）。

敌人行动策略提示词在战斗prompt中给一句话约束:
  "敌人根据自身类型决定战术: 高智敌人优先攻击我方低魔防角色，
   高感敌人优先治疗友方，高力敌人优先攻击前排。"
```

## 十二、战利品

```
战斗胜利后，AI根据以下约束自由决定掉落:

约束:
  ├─ 参考敌方种族和等级，掉落符合世界观
  ├─ 品质 = 用1个d20检定: 1-7普通 8-13稀有 14-17史诗 18-20传说
  ├─ 级别修正: 敌方等级每高1级，品质检定+1
  ├─ 一次战斗最多掉落3张卡牌
  ├─ Boss战必定至少掉落1张稀有以上
  └─ 羁绊卡牌也走同一套品质检定，但额外要求传说品质才出羁绊

掉落默认写入 `stat_data.背包`，作为战利品、材料或未整理卡材。

正式卡牌不会由战斗 AI 直接写入仓库。玩家需要在状态栏中选择背包物品、指定整理方向，由 AI 生成卡牌 JSON，脚本清洗后写入聊天变量卡牌仓库，并消耗对应背包物品。
```

## 十三、AI职责边界

```
AI负责:
  ├─ 全部战斗叙事
  ├─ 全部数值计算（命中/暴击/伤害/波动/MP消耗/HP变更）
  ├─ 状态效果的施加、持续、移除
  ├─ 骰子池按序消费
  ├─ 回合顺序管理
  ├─ 敌人行动决策
  ├─ 地牌被动结算
  ├─ 战后掉落判定
  └─ 输出 MVU 传统变量更新命令

脚本负责:
  ├─ 保存战前快照
  ├─ 注入本回合骰子池
  ├─ 构建 prompt
  ├─ 展示 AI 战斗结果预览
  ├─ 提供 确认写回 / 重试 / 换骰重试 / 放弃
  ├─ 确认后调用 Mvu.parseMessage + Mvu.replaceMvuData
  ├─ 检查变量更新白名单
  ├─ 做 Zod 结构校验和越界保护
  ├─ 战斗最终结束后追加 CombatLog
  ├─ 战斗最终结束后清空敌方
  └─ 放弃或中断时恢复战前快照
```

AI 是战斗主裁判，脚本不是完整战斗引擎。脚本不复算 AI 的命中、伤害、状态和掉落，只保护存档结构和长期系统字段。

AI 禁止修改：

- 卡牌仓库；
- 当前可见区；
- 卡牌加载/槽位；
- 当前可见卡摘要；
- 卡牌 prompt 优先级；
- 卡槽上限；
- `$flag` 系统控制字段；
- 化身永久五维、等级、经验值；
- 战斗中队伍成员增删；
- 队伍永久五维、等级、经验值。

变量更新采用严格允许列表。AI 试图修改非白名单路径时，脚本必须拒绝该更新，并提示玩家，不能静默失败。

战斗经验值、升级和相关恢复由脚本在战斗结束后计算。AI 可以描述战斗规模、表现和奖励线索，但不能直接修改经验值或等级。

战斗 AI 禁止新增或删除队友。新队友加入由主聊天处理：当玩家邀请且对方接受，或 NPC 主动加入时，主聊天 AI 可以直接写入最新楼层 MVU 的 `队伍`。新队友入队时由主聊天 AI 一次性生成初始等级、初始经验、五维、HP/MP、2 个主动技能、1 个被动技能、武器、护甲和背景关系字段。脚本校验字段完整性、稳定 id 和数值范围；校验失败时拒绝写入并提示玩家。队伍人数不设硬上限，不因“满员”阻断写入。离队数据不由 AI 自动删除，由玩家在状态栏手动删除。

战斗中背包物品只有玩家策略明确点名时才能使用或消耗。当前可见卡是否允许 AI 自由调用，由玩家在战斗悬浮窗中选择。

## 十四、战斗 Prompt 结构

发给战斗API的prompt由以下部分组成：

```
1. 本回合骰子池 (默认 d20×20；快速整场战斗 d20×40)
2. 战斗基本规则（本文档一~十二的压缩版）
3. 我方阵容（化身 + 队友）
4. 当前可见战斗卡摘要
5. 背包（AI 可见，但战斗中只能消耗玩家点名物品）
6. 当前状态（buff/debuff/临时效果）
7. 敌方阵容
8. 玩家策略（本回合输入或整场策略）
9. AI 使用当前可见卡方式（自由调用 / 仅点名使用）
```

战斗开始后锁定当前可见区、卡牌仓库操作和背包整理。玩家若要换卡，必须放弃战斗并恢复战前状态后重新开始。

## 十五、战斗流程图

```
遭遇怪物(AI写入stat_data.敌方) → 玩家点「开始战斗」
  │
  ├─ 打开战斗悬浮窗
  │     ├─ 默认回合制，可切换快速整场战斗
  │     ├─ 选择 AI 使用当前可见卡方式
  │     └─ 保存战前快照并锁定状态栏相关操作
  │
  └─ 回合制流程（默认）
        │
        ├─ 玩家输入本回合策略
        ├─ 脚本生成骰子池(d20×20)并构建 prompt
        ├─ 战斗 AI 返回本回合叙事 + 摘要 + UpdateVariable
        ├─ 浮窗展示预览
        ├─ 玩家选择:
        │    ├─ 确认写回 → 解析变量并更新 MVU
        │    ├─ 重试 → 复用同一骰子池重新生成
        │    ├─ 换骰重试 → 重新生成骰子池
        │    └─ 放弃 → 恢复战前快照
        ├─ 确认后更新浮窗UI
        └─ 检查胜负
              │
              ├─ 未结束 → 下一回合
              ├─ 胜利/失败 → 结束战斗
              │     ├─ 将整场纯叙事追加到最新楼层末尾 <CombatLog>...</CombatLog>
              │     ├─ CombatLog 显示折叠，发送 AI 时移除
              │     ├─ 清空 敌方
              │     ├─ 用一句胜败和核心结果覆盖 世界.近期事务
              │     └─ 解锁状态栏
              └─ 中途关闭 → 恢复战前快照，不写 CombatLog
```

快速整场战斗使用同一确认机制，但一次性生成整场过程和最终变量更新。
