# 旅法师战斗系统重规则草案

> 以旅法师战斗系统为主，吸收 `相关系统.txt` 的重规则结构，但按当前讨论重写。  
> 本文只记录当前确认版规则，不覆盖旧设计稿中的实现备注。

---

## 一、等级、位阶与层级

### 1.1 角色等级与黄金黎明位阶映射

- 旅法师战斗体系采用 `31级` 角色等级。
- 位阶节点共 `11段`，写作 `0=0` 至 `10=1`。
- 映射如下：

```text
1-3级   = 0=0
4-6级   = 1=10
7-9级   = 2=9
10-12级 = 3=8
13-15级 = 4=7
16-18级 = 5=6
19-21级 = 6=5
22-24级 = 7=4
25-27级 = 8=3
28-30级 = 9=2
31级    = 10=1
```

### 1.2 三层级划分

- 第一层：`1-15级`，对应 `0=0` 至 `4=7`
- 第二层：`16-27级`，对应 `5=6` 至 `8=3`
- 第三层：`28-31级`，对应 `9=2` 至 `10=1`

层级压制自第二层开始具备明确战斗意义。

## 二、层级压制总则

### 2.1 总原则

1. 同层对抗按常规规则结算。
2. 高一层对低一层形成显著压制；低层仍可凭特殊手段造成有效结果，但常规手段明显受限。
3. 高两层对低两层形成本质碾压；低层常规手段原则上不能造成决定性影响，仅特殊破阶手段可短暂突破。
4. 所谓“特殊手段”，仅包括：明确属性克制、预先布置的仪式、场地或地脉共鸣、已识破并命中的术式弱点、高代价破阶技能、剧情已确认的位格裂口或本质缺陷。
5. 普通攻击、普通控制、常规爆发不视为特殊手段；描述不明确时，一律不算特殊手段。

### 2.2 命中压制

```text
同层：
- 使用 1d20

高一层打低一层：
- 使用 2d20取高
- 低层闪避修正减半

低一层打高一层：
- 使用 2d20取低
- 高层闪避修正视为双倍

高两层打低两层：
- 使用 2d20取高
- 低层闪避修正无效
- 命中评级保底为“有效”

低两层打高两层：
- 无特殊手段时，攻击检定直接无效
- 有特殊手段时，使用 2d20取低
```

### 2.3 伤害压制

```text
同层：
- 正常结算

高一层打低一层：
- 最终伤害 ×1.5

低一层打高一层：
- 最终伤害 ×0.5
- 若无特殊手段，单次伤害上限不得超过目标最大HP的10%

高两层打低两层：
- 最终伤害 ×2.0

低两层打高两层：
- 无特殊手段时，最终伤害视为0
- 有特殊手段时，最终伤害 ×0.25
- 即使形成重创，单次伤害上限不得超过目标最大HP的15%
```

### 2.4 状态与控制压制

```text
高一层打低一层：
- 控制类、削弱类、沉默类、禁锢类检定 +5

低一层打高一层：
- 控制类、削弱类、沉默类、禁锢类检定 -5
- 若无特殊手段，处决、抹杀、概念破坏默认不能成立

高两层打低两层：
- 控制类、削弱类、沉默类、禁锢类效果默认优先成立
- 低层常规抗性减半

低两层打高两层：
- 无特殊手段时，控制类、削弱类、处决类效果直接无效
- 有特殊手段时，相关检定 -10
- 即使成功，默认仅造成短时削弱、破绽或局部失衡
- 只有在“特殊手段成立 + 暴击评级”时，才允许判定为极低概率重创
```

### 2.5 逃跑压制

```text
同层：
- 正常逃跑检定

低一层面对高一层：
- 逃跑检定 -5

低两层面对高两层：
- 逃跑检定 -10

高层追击低层：
- 高一层时，对应追击压制视为 +5
- 高两层时，对应追击压制视为 +10
```

### 2.6 战意压制

```text
同层：
- 按正常战意阈值判定

低层面对高层：
- 面对高一层时，战意触发阈值提前 +10%
- 面对高两层时，战意触发阈值提前 +20%

高层威压低层：
- 若高层在本回合造成暴击、强压制或处决宣言，可额外触发一次战意动摇检定
```

## 三、敌人类型倍率

### 3.1 杂兵

- HP倍率：`×0.6 ~ ×0.8`
- MP倍率：`×0.5 ~ ×0.8`
- 特点：数量优势、单体脆弱、适合集群化
- 规则倾向：优先使用集群规则；被高一层攻击时可被快速清场

### 3.2 精英

- HP倍率：`×1.5 ~ ×2.0`
- MP倍率：`×1.2 ~ ×1.8`
- 特点：拥有完整战斗能力，能稳定释放技能、施加状态、承受数轮战斗
- 规则倾向：通常不并入集群，作为独立单位处理

### 3.3 Boss

- HP倍率：`×4 ~ ×6`
- MP倍率：`×2 ~ ×4`
- 特点：高战意稳定、高状态抗性、可拥有额外机制或被动
- 规则倾向：默认不能被普通清场技轻易结束，适合承接多回合战斗

### 3.4 额外规则

- 杂兵可使用集群单位模板；精英与 Boss 默认不使用集群模板，除非剧情明确说明。
- Boss 面对低一层敌人时，战意阈值延后；面对低两层敌人时，可视情况免除普通战意动摇。

## 四、战斗协议骨架

### 4.1 第一阶段：战况总览

- 每回合开始输出一次。
- 必须列出全部参战单位的：
  - HP / MP
  - 核心属性
  - 当前状态
  - 敌人类型（杂兵 / 精英 / Boss）
  - 是否为集群

### 4.2 第二阶段：行动顺序

- 每回合开始重新计算一次全体行动值。
- 行动值公式：

```text
行动值 = 敏捷 + d20 + 固定修正
```

- 我方、队友、敌方全部进入同一行动轴。
- 按总值从高到低行动。
- 百分比速度修正不作为常规规则；如需特殊改序，优先写成固定修正或直接提前/延后若干位。

### 4.3 第三阶段：攻击行动

- 每单位每回合拥有 `1[攻击]`
- 普攻、攻击技能、伤害法术、带攻击性质的特殊术式均消耗 `1[攻击]`

#### 命中与评级

```text
命中总值 = max(技能命中, 装备命中) + 状态命中修正
闪避总值 = max(技能闪避, 装备闪避) + 状态闪避修正
总值 = d20 + 命中总值 - 闪避总值
```

评级采用四档制：

```text
≤6    = 失手（0倍）
7-12  = 擦伤（0.5倍）
13-18 = 有效（1.0倍）
≥19   = 暴击（1.5倍）
```

#### 伤害公式

```text
基础伤害 = 关联属性 × 10 × 层级系数 + 技能威力 + 装备攻击
最终伤害 = 基础伤害 × 评级系数 × 层级压制修正 × 其他修正
```

#### 集群规则

- 集群用于“同类低级单位数量较多”的情况。
- 杂兵优先进入集群；精英与 Boss 默认不进入集群。
- 高一层攻击第一层杂兵集群时，应允许出现“一次高稀有度大招直接清场”的结果。

#### 特殊手段越级

- 低层对高层若无特殊手段，按层级压制总则直接受限。
- 低层若具备高稀有度技能、高级装备、仪式、状态、道具、环境共鸣或弱点利用，可费力对高层形成有效威胁。
- 若仅差 `1级` 但跨了层级，原则上允许通过充分准备与高代价资源艰难取胜。

### 4.4 第四阶段：战术动作

- 每单位每回合拥有 `1[动作]`
- 防御、道具、逃跑、蓄力、位移、格挡、专注、辅助性术式均消耗 `1[动作]`
- 伤害型道具转入攻击行动结算

### 4.5 第五阶段：战意判定

- 战意判定保留独立模块。
- 除常规阈值外，必须额外受到层级压制总则的战意修正影响。
- 高层对低层可凭暴击、威压、处决宣言追加战意冲击。

### 4.6 第六阶段：战斗结算

- 只有一方全灭、溃逃、投降或成功脱战时输出。
- 写入：
  - 胜败结果
  - 核心战果
  - 状态结算
  - 掉落结算
  - `世界.近期事务` 覆盖

## 六、状态系统草案

### 6.1 状态分类

- 增益：提升属性、命中、闪避、护盾、伤害、抗性、恢复等
- 减益：削弱属性、命中、闪避、防御、抗性、恢复等
- 持续伤害：中毒、灼烧、撕裂、侵蚀、诅咒等按回合结算的伤害
- 控制：沉默、禁锢、迟缓、眩晕、昏迷、恐慌等限制行动状态
- 特殊：护幕、反制印记、易伤、战意侵蚀、召唤维系等不适合归入前四类的效果

### 6.2 属性增益 / 属性减益范围

```text
普通：1-2
优秀：2-4
稀有：4-6
史诗：6-9
传说：9-12
神话：12-18
```

适用对象：

- 力量
- 敏捷
- 体质
- 感知
- 智力
- 命中
- 闪避

说明：

- 具体取值由技能、卡牌、装备、道具决定
- 同类效果是否叠加，优先由具体技能描述决定；未明确时，默认取最高值

### 6.3 百分比增益 / 百分比减益范围

```text
普通：5%-10%
优秀：10%-15%
稀有：15%-25%
史诗：25%-40%
传说：40%-60%
神话：60%-100%
```

适用对象：

- 最终伤害
- 受到伤害
- MP消耗
- 战意抗性
- 治疗效果
- 护盾强度

### 6.4 持续伤害范围

```text
普通：施术者主属性 × 0.2 ~ 0.3 / 回合
优秀：施术者主属性 × 0.3 ~ 0.5 / 回合
稀有：施术者主属性 × 0.5 ~ 0.8 / 回合
史诗：施术者主属性 × 0.8 ~ 1.2 / 回合
传说：施术者主属性 × 1.2 ~ 1.8 / 回合
神话：施术者主属性 × 1.8 ~ 3.0 / 回合
```

说明：

- 具体表现可写为中毒、灼烧、撕裂、侵蚀、咒蚀等
- 持续伤害仍受层级压制、抗性、护幕等修正影响，除非技能明确写为真实伤害

### 6.5 控制类效果门槛

```text
普通：不能施加硬控，仅能造成轻微干扰
优秀：可造成轻度限制，通常不应完整剥夺回合
稀有：可施加沉默、迟缓、短禁锢
史诗：可稳定施加沉默、禁锢、眩晕
传说：可施加强控，但仍受层级压制与抗性制约
神话：可施加高强度控制或复合控制，但不得无视层级压制总则
```

控制状态说明：

- 沉默：不能使用主动法术或主动技能
- 禁锢：不能位移，逃跑检定失败
- 迟缓：敏捷下降，行动值与闪避受罚
- 眩晕：跳过下次攻击或动作
- 昏迷：无法行动，直到持续结束或被强力唤醒
- 恐慌：战意检定额外受罚

### 6.6 状态结算原则

1. 状态效果必须数值化，不接受纯叙事状态名而无明确作用。
2. 状态持续时间按稀有度决定，若技能另有特殊说明，以技能说明为准。
3. 控制类状态默认受 `层级压制总则` 约束：
   - 高层打低层，更容易挂上
   - 低层打高层，无特殊手段基本难以成立
4. 同类持续伤害是否叠加，由技能描述决定；未明确时默认不叠加，仅刷新持续时间或取最高值。
5. 战斗中状态按回合结算；脱离战斗后，如有需要再转换为非战斗持续时间规则。

### 6.7 默认状态书写格式

建议统一写成以下结构：

```text
状态名：效果类型 + 数值 + 层数 + 持续时间 + 来源 + 解除方式 + 结算时机
```

字段建议：

```text
状态名：由 AI 或技能设计自由生成，但应简洁可辨识
效果类型：增益 / 减益 / 持续伤害 / 控制 / 特殊
数值：必须数值化，不接受纯叙事描述
层数：默认1；若支持叠加，必须说明每层效果与叠加上限
持续时间：按稀有度默认时长，或由技能特殊说明覆盖
来源：技能 / 卡牌 / 装备 / 道具 / 仪式 / 环境 / 召唤物 / 其他
解除方式：净化 / 休息 / 特定道具 / 受击解除 / 条件解除 / 持续结束 / 其他
结算时机：回合开始 / 受击时 / 回合结束 / 触发时
```

说明：

- 状态名不预设固定词典，由 AI 结合技能、流派、世界观自由生成。
- 但所有状态都必须落在本节前述范围、门槛与结算规则内。
- 若状态同时包含多个效果，应拆分为清晰的数值条目，避免模糊叙事。
- 若状态具有触发条件，必须在来源或附注中写明，如“受到攻击时”“HP低于30%时”“施法失败时”。
- 若状态可叠层，必须同时写明：
  - 每层提供的数值效果
  - 最大层数
  - 同源叠加是刷新时间、增层，还是两者同时发生

### 6.8 默认结算时机

- `回合开始时结算`
  - 属性增益
  - 属性减益
  - 行动值修正
- `受击时结算`
  - 护幕
  - 易伤
  - 反伤
- `回合结束时结算`
  - 中毒
  - 灼烧
  - 撕裂
  - 咒蚀
- `触发时结算`
  - 战意侵蚀
  - 反制印记
  - 断法

### 6.9 来源、解除与叠层约束

#### 来源字段

- 来源字段至少应说明两层信息：
  - 来源类别：物理 / 魔法 / 精神 / 环境 / 仪式 / 召唤
  - 来源主体：施加者 / 技能名 / 卡牌名 / 装备名 / 道具名 / 区域名

示例：

```text
来源：魔法-灰烬之枪
来源：环境-毒沼雾区
来源：仪式-逆五芒封锁阵
来源：召唤-镜像猎犬
```

#### 解除方式

- 状态原则上都应存在可说明的解除路径，除非技能明确写为永久或不可净化。
- 常见解除方式：
  - 持续结束
  - 净化法术
  - 特定道具
  - 休息恢复
  - 受击解除
  - 离开区域
  - 达成特定条件

#### 触发条件

- 以下情况应明确写触发条件：
  - 触发型状态
  - 条件型状态
  - 反制型状态
  - 低血量强化或低血量失控状态

示例：

```text
触发条件：受到攻击时
触发条件：HP低于30%时
触发条件：尝试施法时
触发条件：回合结束时
```

#### 叠层规则

- 默认层数为 `1`
- 若技能未说明可叠层，则默认不叠层，仅刷新持续时间或取最高值
- 若技能说明可叠层，必须补充：
  - 每层效果
  - 最大层数
  - 同源叠加规则
  - 异源叠加规则

默认叠层口径：

```text
同名同源：优先刷新时间，其次增层
同名异源：默认独立计时；若过于复杂，可改为取最高值
```

## 七、战意判定草案

### 7.1 触发条件

- 仅非玩家单位触发战意判定
- 当目标当前 HP 低于其战斗类型对应阈值时触发
- 除常规阈值外，还需叠加 `层级压制总则` 中的战意提前修正

### 7.2 战斗类型与战意阈值

```text
切磋：40%
竞技：30%
压制：50%
标准：30%
守卫：35%
死斗：10%
```

判定口径：

- 切磋 / 竞技 / 压制：触发后默认进入“战意动摇”
- 标准 / 守卫 / 死斗：触发后进行一次战意检定，再决定是否崩溃

### 7.3 战意检定

```text
d20 < 12：丧失战意 / 崩溃
d20 ≥ 12：勉强坚持
```

修正来源：

- 层级压制
- 恐慌、威压、处决宣言
- Boss 的战意稳定修正

### 7.4 结果池

战意动摇或崩溃后，可从以下结果中选取最符合情境的一项：

- 投降
- 认输
- 求饶
- 溃逃
- 撤退
- 被击昏
- 被俘虏
- 中止战斗
- 阵线溃散
- 内讧

说明：

- 结果池不包含“直接死亡”
- 是否处决目标，必须由攻击行动或明确处决宣言处理，不由战意判定直接带出死亡

### 7.5 特殊对象修正

- 杂兵：更容易触发战意动摇，可优先进入溃逃、溃散、求饶结果
- 精英：默认按正常规则处理
- Boss：可延后触发阈值，并对普通战意动摇具备额外抗性

---

## 八、设计目标

1. 第二层应能以高稀有度技能或大招快速清理 `0=0` 杂兵与小型第一层集群。
2. 精英与 Boss 必须通过额外倍率拉开生存时间，避免被高层随手清空。
3. 低层面对高层时，常规手段应明显吃力，但允许通过仪式、装备、状态、道具、高稀有度技能等组合资源费力打过。
4. 规则先偏保守，后续以实战结果再调表，不在首轮草案中追求极限数值。
