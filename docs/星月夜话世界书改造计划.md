# 星月夜话世界书改造计划

> 目标: 模仿命定之诗结构，对星月夜话世界书进行数据库格式改造
> 阶段: 第一层·世界观基础

---

## 一、改什么

### 1.1 格式转换: 散文 → 数据库

**现状:**
```yaml
描述: 星月市是一座面向太平洋的现代化都市，人口约350万。
城市以中央区的星月塔为地标，由七个行政区组成。这是一座
表里共存的都市——普通人在阳光下过着平凡的日常，而阴影中，
超自然势力们进行着不为人知的博弈。
```

**改造后:**
```yaml
星月市:
  定位: 太平洋沿岸现代化都市
  人口: 350万
  性质: 表里共存都市
  地标: 星月塔(中央区·城市核心)
  行政区: 中央区/东月区(老城)/西海区(港口)/南星区(商业)/北郊(山区)/樱台学园都市
  原则: 隐藏原则为最高铁律
```

### 1.2 拆分: 角色详情.yaml → 独立世界观条目

`角色详情.yaml` 目前混装了：
- 地理 → 拆到 `星月地理.yaml`
- 历史 → 拆到 `星月历史年表.yaml`
- 世界规则 → 拆到 `世界观总纲.yaml`

### 1.3 新增: 缺失的规则层

命定之诗有三层规则结构：
1. **世界观总纲** — 世界是什么、核心矛盾、氛围基调
2. **世界底层规则** — AI如何处理输入、逻辑防火墙、校验流程
3. **超自然力量体系** — 力量分类、相性克制、等级

星月夜话完全缺少 1 和 2，3 只在 角色详情.yaml 末尾有4行。

  世界规则:
    隐藏原则: 任何势力不得向普通人暴露超自然存在

    诅咒法则: 邪神诅咒是力量的来源也是侵蚀的根源

## 三、index.yaml 注册方式

需要新增一个锚点类型用于世界观条目：

```yaml
- &世界观条目
  启用: true
  激活策略:
    类型: 蓝灯                     # constant
  插入位置:
    类型: 角色定义之前              # ↑Char (pos 0)
    顺序: 100                      # order
  递归:
    不可被其他条目激活: true
    不可激活其他条目: true
```

注册后目录结构新增节：
```yaml
- 文件夹: 世界观
  条目:
    - 名称: 世界观总纲
      <<: *世界观条目
      文件: 世界书/世界观总纲
    - 名称: 世界底层规则
      <<: *世界观条目
      顺序: 110
      文件: 世界书/世界底层规则
    - 名称: 星月市地理
      <<: *世界观条目
      顺序: 120
      文件: 世界书/星月地理
    ...
```

各个世界观条目的顺序从 100 开始，每 +10：
- 100: 世界观总纲
- 110: 世界底层规则
- 120: 星月地理
- 130: 星月历史年表
- 140: 势力关系总览
- 150: 超自然力量体系
