## 三、内容格式

### 3.1 主要格式

**YAML 缩进风格 (142条)** — 最常用，适用于世界设定、地点、角色

```yaml
---
条目名:
  键: 值
  子键:
    子子键: 值
  列表项: |
    多行文本可在此
    用缩进延续
```

**散文风格 (362条)** — 较短的条目、标记、规则描述

**XML风格** — 用于核心规则、系统指令

```xml
<虚海规则>
  核心法则: ...
</虚海规则>
```

### 3.2 核心写作原则

1. **数据库格式，不是散文**：列表/键值对为主，极少连接词
2. **用最少的字说清所有设定**：连接词用冒号/逗号/列举替代
3. **只写AI不知道的信息**：不写常识
4. **不写主观形容词**：不写"强大的""神秘的""美丽的"

### 3.3 YAML 中的助记标记

```
品质前缀: 史_(史诗) / 稀_(稀有) / 良_(优秀) / 普_(普通)
层级标记: 第一层~第六层(神话)
数量/群体: 3~6单位 | 单体/群体
定位标记: (政治中心) / (注释说明)
列表分割: 逗号,或|竖线
```

## 六、关键词策略

### 6.1 覆盖范围

- 覆盖所有称呼：全名、昵称、外号、职务
- 英文逗号 `,` 分隔（中文逗号无效）
- 不要空格

### 6.2 关键词数量

- 势力/城市：2-7 个
- 角色：2-5 个
- 种族/怪物：3-10 个（覆盖别名）
- 产业/功能：5-15 个（覆盖所有相关动作）

### 6.3 激活策略

| 卡类型 | 策略 |
|--------|------|
| 单角色卡 | 全部 constant |
| 位置条目(城市/野怪) | selective，关键词触发 |
| 角色条目 | selective，角色名触发 |
| 世界观/规则 | constant |
| 章节标记 | constant |

### 6.4 技术配置

```json
{
  "preventRecursion": true,    // 所有条目必须
  "excludeRecursion": true,    // 部分条目有
  "scanDepth": 2,              // selective条目
  "depth": 4,                  // 大部分pos=0/1的深度
  "selective": true,           // 非constant的条目
  "selectiveLogic": 0          // 默认OR逻辑
}
```

## 八、总结：如何模仿命定之诗

### 快速上手步骤

1. **先写标记条目**：`➡️XXX开始/结束`，定义你世界的各大章节
2. **写世界观总纲**：pos=0, constant，定义世界核心规则
3. **写势力概览**：pos=0, selective，各大国家和组织
4. **写城市/地点**：pos=0, selective，具体场景
5. **写种族**：pos=0, selective，定义种族特性
6. **写角色**：pos=1, selective，DLC角色格式
7. **写规则**：pos=4, constant，战斗/生产/变量规则

### 格式要点

- **数据库格式**：YAML缩进，key: value，少散文
- **助记标记**：品质前缀、层级标记
- **只写差异**：不写AI已知的常识
- **极度压缩**：用冒号/逗号/列举替代连接词
- **关键词全面**：覆盖所有称呼

### 技术要点

- 所有条目加 `preventRecursion`
- 英文逗号分隔关键词
- 单角色卡全部 constant
- selective 条目加 `scanDepth: 2`
- 规则条目用 depth: 0~2, role: 0
